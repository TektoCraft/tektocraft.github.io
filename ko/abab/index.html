스크린샷

ABAB는 사진 속 얼굴을 찾아 한 번의 탭으로 눈을 가리거나 얼굴을 흐리게 합니다. 사진을 고르거나 찍은 뒤 버튼만 누르세요. 모든 처리는 기기 안에서 이루어지며, 사진은 업로드되지 않습니다.

주요 기능

  • 카메라로 촬영하거나 사진 보관함에서 선택
  • “눈 가리기”: 눈 위에 검은 띠
  • “흐림”: 사진 속 모든 얼굴을 흐리게
  • 두 기능을 함께 쓸 수 있고, “원본”으로 언제든 되돌릴 수 있습니다

이럴 때
SNS나 블로그에 올리기 전에 사진 속 사람들의 프라이버시를 지키고 싶을 때.

프리미엄(1년 단위 자동 갱신 구독)
프리미엄으로 편집한 사진을 저장할 수 있고 광고가 사라집니다. 가격과 갱신 기간은 구독 전에 앱에 표시됩니다. 구입 복원도 언제든 가능합니다.

결제는 구입 확인 시 Apple 계정으로 청구됩니다. 현재 기간이 끝나기 최소 24시간 전에 해지하지 않으면 구독이 자동으로 갱신됩니다. 갱신 요금은 현재 기간이 끝나기 전 24시간 이내에 청구됩니다. 구입 후에는 Apple 계정 설정에서 구독을 관리하거나 해지할 수 있습니다.

개인정보 보호
사진은 기기 안에서 처리되며 어디로도 전송되지 않습니다. 프리미엄이 아니면 광고(Google AdMob)가 표시됩니다.
